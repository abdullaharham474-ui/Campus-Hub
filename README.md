# Smart Campus Website

## Setup
1. Install Python.
2. Open this project folder in VS Code.
3. In Terminal, run:
   `python -m pip install -r requirements.txt`
4. Start:
   `python app.py`
5. Visit http://127.0.0.1:5000

Default demo admin:
- Email: admin@smartcampus.com
- Password: Admin123!

Change the demo password/secret key and disable debug mode before deploying publicly.
This is a starter project for local testing. HTTPS and secure cookie configuration are required for production.
